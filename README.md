# 🧠 QA + Dev AI Copilot

AI-powered assistant to convert requirements into structured QA test cases.

## 🚀 Features

- 🔐 PII masking before AI processing
- 🧪 Structured test case generation
- 📊 CSV export
- 🧐 Test coverage feedback (critic agent)
- 📂 File processing (PDF, DOCX, Images)

## 🛠️ Tech Stack

- Python
- Streamlit
- OpenAI (gpt-4o-mini)

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
